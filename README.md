# preflight-checklist

777 preflight checklist for the iPad: required briefings on the left, required paperwork on the right. It installs to the Home Screen (Safari, then Share, then Add to Home Screen), runs full screen, and works offline after the first open.

Live at https://gk9tzsb8jy-lang.github.io/preflight-checklist/

When you change `index.html`, bump `VERSION` in `sw.js` so iPads pick up the new copy.
